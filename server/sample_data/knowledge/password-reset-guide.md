# Password Reset Guide

Anyone can reset their password from the sign-in page. Support agents cannot see or set customer passwords.

## Sending a reset link

1. Go to the sign-in page and click **Forgot password**.
2. Enter the email address used for the account.
3. Open the email titled "Reset your password" and click the link.

The reset link is valid for 30 minutes and can only be used once. Requesting a new link invalidates any earlier links.

## The reset email did not arrive

- Check the spam or junk folder, and search for mail from no-reply@example.com.
- Make sure the address is the one on the account. Work accounts are often registered with a different alias.
- Corporate mail filters sometimes delay messages by up to 15 minutes.

If the email still does not arrive, the agent can confirm the account email and trigger a new link from the admin console.

## Signing in after a reset

Old sessions on other devices are signed out after a password reset. If the customer still sees "invalid credentials" right after resetting, ask them to:

- clear saved passwords for the site in their browser or password manager,
- try a private/incognito window,
- check that Caps Lock is off.

If the account uses single sign-on (SSO), the password is managed by the customer's identity provider and cannot be reset here.
