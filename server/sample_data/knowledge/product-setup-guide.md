# Product Setup Guide

## Creating a workspace

After signing up, the first user becomes the workspace owner. The owner can rename the workspace and upload a logo under **Settings → General**.

## Inviting teammates

Go to **Settings → Members → Invite**. Invitations expire after 7 days. Invited users who do not see the email should check spam, or the admin can copy the invite link and send it directly.

## Roles

- **Owner** — full access, including billing and deleting the workspace.
- **Admin** — manage members, projects and integrations.
- **Member** — create and edit projects they belong to.
- **Guest** — view and comment on shared projects only.

## Importing data

CSV imports are available under **Projects → Import**. The file must be UTF-8 and include a header row. Imports are limited to 10,000 rows per file.

## Exporting data

Reports can be exported to CSV or PDF. If an export contains only the header row, the report filters probably exclude everything — ask the customer to clear filters and export again. Exports larger than 50,000 rows are emailed as a download link instead of downloading in the browser.

## Integrations

Slack and Google Calendar integrations are set up under **Settings → Integrations**. Integrations are connected per user, so each teammate has to connect their own account.
